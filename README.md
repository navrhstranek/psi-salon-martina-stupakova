# Psí salon Martina Štupáková

Web: https://navrhstranek.github.io/psi-salon-martina-stupakova/

Statický web salonu v Rožnově pod Radhoštěm. GitHub Actions po změně větve `main` publikuje složku `public/`.

Kontaktní formulář připravuje zprávu v e-mailové aplikaci návštěvníka; návštěvník ji odešle sám. Fotografie jsou ilustrační, zdroje a licence jsou v `public/assets/salon/fotky/ZDROJE.md`. Font Caveat a jeho licence jsou v `public/assets/salon/pismo/`.
